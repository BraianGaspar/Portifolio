# 👨‍💻 Meu Portfólio - Braian Gaspar da Rosa

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido para apresentar minhas habilidades, projetos e experiência como desenvolvedor Full Stack, com foco em back-end, automação e Inteligência Artificial.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Design responsivo (mobile, tablet e desktop) e animações
- **JavaScript** - Interatividade, troca de idioma e formulário funcional
- **GitHub Pages** - Hospedagem

## 🌐 Idiomas

O portfólio está disponível em **Português**, **Inglês** e **Espanhol**. O seletor PT | EN | ES fica no cabeçalho, e o idioma escolhido é lembrado na próxima visita.

### Estrutura de seções

1. **Hero** - Apresentação principal
2. **Sobre** - Informações pessoais e profissionais
3. **Habilidades** - Stack tecnológica
4. **Experiência** - Trabalho e formação
5. **Projetos** - Repositórios em destaque
6. **Contato** - Formulário e redes sociais

## 💻 Rodando localmente

O site é estático, então basta servir a pasta com qualquer servidor HTTP:

```bash
npx http-server -p 8080 -c-1 .
```

Depois acesse `http://localhost:8080`.
