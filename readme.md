# 👨‍💻 Meu Portfólio - Braian Gaspar da Rosa

Bem-vindo ao repositório do meu portfólio profissional! Este projeto foi desenvolvido para apresentar minhas habilidades, projetos e experiência como desenvolvedor Full Stack.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Design responsivo e animações
- **JavaScript** - Interatividade e formulário funcional
- **GitHub Pages** - Hospedagem

## 📱 Funcionalidades

- ✅ Design responsivo (funciona em desktop, tablet e mobile)
- ✅ Smooth scroll para navegação entre seções
- ✅ Animações de entrada (scroll reveal)
- ✅ Formulário de contato funcional (integração com WhatsApp)
- ✅ Cards de projetos com links para repositórios reais
- ✅ Informações profissionais atualizadas
